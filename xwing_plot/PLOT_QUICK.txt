X-wing 實飛畫圖 最簡流程          詳細: PLOT_STEPS.txt / PLOT_GUIDE.md

【今晚 (只做一次)】
1. GitHub 分支 claude/funny-gates-j8j7f7 → Code → Download ZIP → 覆蓋筆電 x-wing_vision_flight
2. 進 x-wing_vision_flight\xwing_plot → 路徑列輸入 cmd → Enter
   python test_plot_report.py --vision
   看到 [test] 完成 = OK

【飛行時】
啟動指令不要加 --no-vision (雲台資料才會記錄)
落地後 Terminal 2 輸入 q + Enter

【落地後】
1. Orin 的 flight_logs 資料夾 → 隨身碟 → 覆蓋 x-wing_vision_flight\flight_logs
     cp -r ~/catkin_ws/src/x-wing_vision_flight/flight_logs /media/$USER/<隨身碟>/ && sync
2. 車子 SD 卡 LOGS\ 當天的 .BIN → 放進 x-wing_vision_flight\xwing_plot\car_bin\
   (沒有 car_bin 就新建; 沒有車子 BIN 也能畫, 只是少真車比較)
3. 進 x-wing_vision_flight\xwing_plot → 路徑列輸入 cmd → Enter
   python xwing_plot_report.py --all

【看結果】 xwing_plot\plot_results\<log 檔名>\run1\
   report.pdf    → 全部圖, 給老師看
   summary.txt   → ⚠ = 要看的參數; 【雲台資料當控制命令】= 雲台能不能拿來控制

【log 太大傳不上來】 (只切出要分析的趟次, 再壓成 zip)
   python cut_log.py                      → flight_logs\cut\<log 名>_cut.zip, 傳這個
   python cut_log.py <log 檔名> --run 3 4  → 只切第 3、4 趟

【整份 CSV 要傳, 但超過上限】 (切成幾份, 每份都有表頭; --zip 每份再壓縮)
   python split_csv.py <log 檔名> --zip          → flight_logs\split\<log 名>_part1of3.zip ...
   python split_csv.py <log 檔名> --parts 4 --zip

【車子 BIN 太大傳不上來】 (只抽 GPS, 幾十 MB → 約 0.3 MB)
   python car_gps_extract.py <車子 BIN 路徑>   → <BIN 名>_gps.json.gz, 傳這個

【飛控 BIN 太大傳不上來】 (只抽出轉彎分析要的部分, 幾百 MB → 1~3 MB)
   python bin_extract.py <飛控 BIN 路徑>   → <BIN 名>_turns.json.gz, 傳這個

【雲台什麼時候有資料 / 斷線時飛機在哪】 (要用完整 log, 不是 cut 的)
   python gimbal_timeline.py <log 檔名>    → 有資料的時段 + 當時 AGL/空速 + 每趟涵蓋率
【雲台斷線原因】 (10/30 以後的飛行程式; flight_logs 要有 <log 名>_uart_raw.bin)
   python uart_diag.py <log 檔名>          → plot_results\<log 名>\uart\uart_diag.txt + .png
   看「斷線期間我們送出」(TX 正常?) 和「對方封包編號跳多少」(對方有沒有在算)
   cut_log.py 產生的 zip 會自動附上這些診斷檔

【出錯時】
找不到 log        → flight_logs 要在 x-wing_vision_flight\flight_logs (不是 xwing_plot 裡)
can't open file   → cmd 要從 xwing_plot 資料夾開
沒有 GUIDED 段    → 地面測試, 加 --full
其他              → 整個畫面拍下來

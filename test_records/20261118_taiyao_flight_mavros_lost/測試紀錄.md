## 原因：程式開始 38.7 s 後，MAVROS (飛控) 資料整個停了

| 證據 | 內容 |
|---|---|
| events | **整份沒有「★ GUIDED 上升沿」**，模式鍵送出 0 次 → 程式從來沒發現撥了 GUIDED，**沒有開始任務、沒有送任何命令** |
| 程式看到的飛控模式 | 3,087 s 全程都是 **MANUAL** |
| 飛控資料 | 姿態、空速、高度、電池、GPS **在 t = 38.66 s (約 11:47:26) 同一瞬間全部停止更新**，之後一直停在地面時的值 (AGL ≈ 0、位置不變) |
| 程式本身 | 控制迴路照常 50 Hz、雲台 UART 資料一直更新到最後 → **程式沒有當掉，只有 MAVROS 這條斷了** |

所有飛控話題同時停住 → **MAVROS 跟飛控之間的連線斷了**。
→ 飛控 log 確認：**飛控在 11:47:26 重開機，MAVROS 沒有重新連上** (見下一節)。

### 為什麼會「直接右轉」
撥 GUIDED 後飛控在等外部命令，但程式不知道 GUIDED、而且 MAVROS 斷了也送不出去
→ ArduPlane **GUIDED 沒收到命令時會在當下位置繞圈 (預設順時針 = 往右轉)**。
所以「直接右轉」不是程式下的命令，是飛控 GUIDED 的預設行為。

## 飛控 log (00000004.BIN) 確認：飛控在 11:47:26 重開機，MAVROS 沒有重新連上

`fc_00000004.BIN.7z` (ArduPlane V4.5.4, FlightCoreH7)，記錄 11:49:33 ~ 12:43:35。

| 證據 | 內容 | 代表 |
|---|---|---|
| 開機訊息 | 第一筆就是 `ArduPlane V4.5.4 / ChibiOS / FlightCoreH7`，此時飛控開機已 127.3 s | 開機時間 = 11:49:33 − 127.3 s = **11:47:26** |
| 我們的 log | MAVROS 資料停在 **11:47:26** (程式 t = 38.66 s) | **同一秒** → 飛控重開機，USB 跟著斷開再接回 |
| POWR Flags | 全程 = 7 (USB 連著的旗標一直有) | USB 線實體上是接著的 |
| MAV 通道 0 (USB) | 收到 Orin 的封包 **0 筆**；送出緩衝區滿的次數 11,731 → 45,670 一直增加 | 飛控一直想從 USB 送資料，**Orin 那端沒有人在讀** → MAVROS 還接在重開前那個已經消失的 USB 裝置上，沒有重新連 |
| MAV 通道 1 (數傳) | 一直有收送 | Mission Planner 正常，所以地面站看得到飛機 |
| MODE | 12:06:55 GUIDED (地面站切) 27 s、12:09:05 GUIDED 30 s，之後切回 AUTO | 就是兩次「撥 GUIDED」 |
| GUIDED 期間 ATT | 飛控**自己要求 roll ≈ +30°**，航向右轉 228° / 257° | ArduPlane GUIDED 沒有外部命令時的**繞圈 (往右)** |
| 電池 | log 一開始 (11:49:33) 主電池 (BAT1) 已經是 58 V；我們的 log 在 11:47:26 前只有 8.3 V 那顆 (主電池那顆讀 0.01) | 主電池是在 11:47:26 前後接上的 → **很可能是接主電池時造成飛控重開機** (log 從開機後才開始記，無法 100% 確定) |
| ERR | 沒有 | 飛控本身沒有錯誤 |

### 結論
1. **11:47:26 飛控重開機** (時間跟主電池接上吻合)。
2. 重開機時飛控的 USB 斷開再接回，**MAVROS 不會自己重連**，之後整趟都收不到飛控資料。
3. 程式不知道撥了 GUIDED → 沒開始任務；飛控 GUIDED 沒命令 → 自己往右繞圈。

### 以後怎麼避免
- **開機順序**：先把飛機的電 (主電池 + 8 V 電池) 全部接好、飛控開機完成，**再開 MAVROS、再開飛行程式**。
- 只要中途飛控重開過 (換電池、插拔電源、寫參數重開)，**MAVROS 和飛行程式都要重開**。
- 新版程式的飛控資料看門狗會在 1 s 內警告 `★★★ 飛控 (MAVROS) 資料中斷`，撥 GUIDED 也會拒絕啟動；
  狀態列 AGL / V 不會動也是一個訊號。
- 建議查一下接主電池時為什麼會讓飛控重開 (瞬間電流造成飛控供電掉壓？防火花接頭、電源模組 / BEC)。

   - 撥 GUIDED 時**拒絕啟動任務** (原因寫「飛控資料中斷」)

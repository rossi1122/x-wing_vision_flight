## 結論

**程式開始後前 241 s 對方完全沒有送資料；從 241 s 開始到結束，傳輸都正常。**
影像延遲一樣約 260 ms。這次 SEARCH 時**沒有**雲台自己切到鎖定。

### 1. 開頭 241 s 沒有資料 (對方還沒開始送)

| 時段 | 狀況 |
|---|---|
| 0 ~ 114.5 s | 一個 byte 都沒收到 |
| 114.5 s | 收到 1 個 byte，之後又沒有 |
| 132.4 s | 再收到 1 個 byte，之後又沒有 |
| **241.0 s** | **開始正常收封包**，之後到結束都沒有中斷 |

判斷：**對方那邊在 241 s 才開始送** (程式還沒開 / 開機中)；零星的 1 個 byte 應該是對方板子上電或接線時的雜訊。
- 埠全程存在、串口全程開著 → 我們這邊 USB-UART 沒有掉。
- kernel 訊息 (`_dmesg_*_rxlost.txt`) 只有 Orin Wi-Fi 掃描的訊息，**沒有 USB / 串口斷線的訊息**。
- 斷線期間我們沒有送任何東西 (沒收過有效封包前不送校時、STANDBY 不送模式鍵)，正常。
- 實飛時：**開飛行程式前先確認對方雲台已經在送** (狀態列 `VIS link=1`)。

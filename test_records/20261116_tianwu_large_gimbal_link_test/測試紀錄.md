## 這次的資料特性 (田屋大雲台)

- **封包格式：舊版 v8** (不是共用接收端 V6 的新格式 0~5 / 10)，所以沒有 yaw 欄位。程式兩種都收。
- **相機內參**：fx 1766.3 / fy 1764.1，cx 960 / cy 540，影像 1920×1080。
- **雲台 pitch / roll / angle_age / 雷射：100 % NaN** — 控制板故障中，預期內 (已從原始 byte 確認是對方送出 NaN)。
  → 偵測沒辦法換算成角度 / 距離 (log 的 `vg_valid` 全 0)。
- 目標像素：撥 GUIDED 後約 55 % 有偵測到東西，位置在畫面左邊約 15~20° (雲台沒有角度回授，追蹤沒有作動)。

## 等控制板修好後要再確認

1. 雲台 pitch / roll 有數值 (`uart_mipi_receiver.py` 的「雲台 Pitch 角度」不是 N/A)。
2. 按 `1` 追蹤時，目標會被拉到畫面中央附近。
3. 如果改送新格式 (版本號 0~5 / 10)，再接一次確認連線，並看 yaw 欄位。
4. 之後做地面校正：`python3 gimbal_calib.py`。
